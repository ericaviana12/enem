1. Números e Operações

1.1 Conjuntos Numéricos

Os números podem ser classificados em diferentes conjuntos, cada um com características específicas:

  • ℕ (Números Naturais): Números inteiros não negativos, usados para contagem (0, 1, 2, 3, ...).
  • ℤ (Números Inteiros): Incluem os naturais e seus opostos negativos (..., -3, -2, -1, 0, 1, 2, 3, ...).
  • ℚ (Números Racionais): Números que podem ser escritos na forma de fração a/b, onde a e b são inteiros e b ≠ 0 (ex.: 1/2, -4/3, 0, 5).
  • ℝ (Números Reais): Incluem os racionais e os números irracionais, que não podem ser escritos como fração (ex.: √2, π).
Por exemplo, o número 7 é um natural, inteiro, racional e real. Já o número √2 é irracional, mas é real.

1.2 Operações Básicas

As quatro operações fundamentais da matemática são:

  • Soma (+): Combina valores para obter o total. Exemplo: 3 + 5 = 8.
  • Subtração (-): Diferença entre valores. Exemplo: 10 - 6 = 4.
  • Multiplicação (×): Soma repetida de um número. Exemplo: 4 × 3 = 12.
  • Divisão (÷): Distribuir um número em partes iguais. Exemplo: 12 ÷ 4 = 3.

1.3 Potência e Raiz

A potência representa uma multiplicação repetida. Por exemplo, 2^3 significa 2 multiplicado por ele mesmo 3 vezes:

2^3 = 2 × 2 × 2 = 8

A raiz quadrada é a operação inversa da potência ao quadrado. Por exemplo:

√25 = 5 porque 5^2 = 25.

Importante: Existem raízes quadradas de números negativos, mas elas não pertencem ao conjunto dos números reais.

1.4 MMC e MDC

MMC (Mínimo Múltiplo Comum) é o menor número múltiplo de dois ou mais números.
MDC (Máximo Divisor Comum) é o maior número que divide dois ou mais números sem deixar resto.

Esses conceitos são úteis para operações com frações e para simplificar expressões.

Exemplo:
  • MMC de 4 e 6 = 12
  • MDC de 12 e 16 = 4

1.5 Propriedades das Operações

  • Comutativa: A ordem dos números não altera o resultado (ex.: 3 + 5 = 5 + 3).
  • Associativa: A forma de agrupar números não altera o resultado (ex.: (2 + 3) + 4 = 2 + (3 + 4)).
  • Distributiva: Multiplicação distribuída sobre a soma (ex.: 3 × (4 + 2) = 3×4 + 3×2).

2. Álgebra

2.1 Equações

Equações são expressões matemáticas que afirmam a igualdade entre duas expressões, usando uma variável (geralmente x). São usadas para encontrar valores desconhecidos.

  • Equação do 1º grau: tem a forma ax + b = 0, onde a ≠ 0. Exemplo: 2x + 5 = 11.
  • Equação do 2º grau: tem a forma ax² + bx + c = 0, onde a ≠ 0. Exemplo: x² - 5x + 6 = 0.

2.2 Fórmula de Bhaskara

Para resolver equações do 2º grau, usa-se a fórmula:

x = (-b ± √Δ) / 2a

Onde Δ (delta) é o discriminante, calculado por: Δ = b² - 4ac.

Exemplo: Resolver x² - 5x + 6 = 0
  • a = 1, b = -5, c = 6
  • Δ = (-5)² - 4×1×6 = 25 - 24 = 1
  • x = [5 ± √1] / 2 = (5 ± 1) / 2
  • x₁ = (5 + 1) / 2 = 3
  • x₂ = (5 - 1) / 2 = 2
Portanto, as soluções são x = 3 e x = 2.

2.3 Fatoração e Produtos Notáveis

A fatoração consiste em escrever uma expressão como produto de fatores. Exemplos importantes:

  • Produto da soma pela diferença: (a + b)(a - b) = a² - b²
  • Quadrado da soma: (a + b)² = a² + 2ab + b²
  • Quadrado da diferença: (a - b)² = a² - 2ab + b²
  • Cubo da soma: (a + b)³ = a³ + 3a²b + 3ab² + b³
  • Cubo da diferença: (a - b)³ = a³ - 3a²b + 3ab² - b³

2.4 Sistemas Lineares

Sistemas são conjuntos de duas ou mais equações com variáveis comuns, que devem ser resolvidos simultaneamente. Métodos para resolver:

  • Substituição: Isola-se uma variável e substitui na outra equação.
  • Adição (ou Combinação): Soma ou subtrai as equações para eliminar uma variável.
  • Escalonamento: Multiplica-se equações para facilitar a eliminação.

3. Funções

Função é uma relação que associa cada elemento do conjunto de entrada (domínio) a um único elemento do conjunto de saída (contradomínio).

3.1 Função Afim

Forma: f(x) = ax + b, onde a e b são constantes.

Representa uma reta no plano cartesiano.

3.2 Função Quadrática

Forma: f(x) = ax² + bx + c, onde a ≠ 0.

Gráfico em formato de parábola. Pode abrir para cima ou para baixo, dependendo do sinal de a.

3.3 Função Exponencial

Forma: f(x) = aˣ, onde a > 0, a ≠ 1.

Usada para modelar crescimento ou decrescimento exponencial, como juros e crescimento populacional.

3.4 Função Logarítmica

Forma: f(x) = logₐx, inversa da função exponencial.

Usada para resolver equações onde a variável está no expoente.

Funções são muito usadas para analisar dados, criar gráficos, calcular juros compostos, entre outras aplicações.

4. Geometria

4.1 Geometria Plana

  • Quadrado: Área = l², onde l é o lado.
  • Triângulo: Área = (b × h) / 2, base vezes altura dividido por dois.
  • Círculo: Área = πr², Perímetro (circunferência) = 2πr.

4.2 Geometria Espacial

  • Cubo: Volume = a³, onde a é a aresta.
  • Cilindro: Volume = πr²h, área da base vezes altura.
  • Esfera: Volume = (4/3)πr³.
  • Teorema de Pitágoras: Em triângulos retângulos, a² = b² + c².

5. Trigonometria

  • Seno (sen θ): Razão entre o cateto oposto e a hipotenusa.
  • Cosseno (cos θ): Razão entre o cateto adjacente e a hipotenusa.
  • Tangente (tan θ): Razão entre o cateto oposto e o cateto adjacente.
  • Identidade fundamental: sen²θ + cos²θ = 1.

6. Estatística e Probabilidade

6.1 Estatística

  • Média: Soma dos valores dividida pela quantidade de valores.
  • Moda: Valor que aparece com maior frequência.
  • Mediana: Valor central quando os dados estão ordenados.
  • Desvio padrão: Mede a dispersão dos dados em relação à média.

6.2 Probabilidade

A probabilidade mede a chance de ocorrência de um evento, calculada por:

Probabilidade = (casos favoráveis) / (casos possíveis)

  • Eventos independentes: A ocorrência de um não afeta o outro.
  • Eventos dependentes: A ocorrência de um altera a chance do outro.

7. Matemática Financeira

  • Juros Simples: J = C × i × t, onde C é o capital, i a taxa e t o tempo.
  • Juros Compostos: M = C × (1 + i)^t, M é o montante acumulado.
  • Porcentagens: Usadas para calcular aumento, desconto e variação percentual.

8. Análise Combinatória

  • Permutação: Número de maneiras de ordenar n elementos: n!.
  • Arranjo: Número de maneiras de ordenar p elementos dentre n: A(n,p) = n! / (n - p)!.
  • Combinação: Número de grupos de p elementos dentre n, sem ordem: C(n,p) = n! / [p!(n - p)!].

9. Matrizes e Geometria Analítica

  • Matriz 2x2 e determinante: Para matriz [[a, b], [c, d]], o determinante é ad - bc.
  • Equação da reta: y = mx + n, onde m é o coeficiente angular (inclinação) e n o intercepto.
  • Distância entre dois pontos: d = √[(x₂ - x₁)² + (y₂ - y₁)²].

10. Gráficos e Interpretação

  • Leitura de gráficos de barras, linhas e setores (pizza).
  • Variação percentual para entender crescimento ou redução.
  • Identificação de tendências: crescimento constante, queda ou estabilidade.

11. Dicas de Estudo e Estratégias para a Prova

  • Pratique todos os dias: Matemática é uma disciplina prática. Reserve um tempo diário para resolver exercícios variados.
  • Entenda os conceitos, não decore: Foque em compreender as ideias por trás das fórmulas e procedimentos.
  • Use mapas mentais e resumos: Organize o conteúdo em esquemas visuais para facilitar a memorização.
  • Resolva provas antigas: Pratique com questões do ENEM, FUVEST e outras para entender o estilo das perguntas.
  • Estude em grupos: Trocar dúvidas e explicar o conteúdo para colegas reforça o aprendizado.
  • Tenha paciência e mantenha a motivação: Alguns temas são mais difíceis, mas a persistência traz resultado.
  • Utilize recursos multimídia: Vídeos, apps, jogos e simuladores ajudam a fixar o conteúdo.
  • Reforce os fundamentos: Sempre volte aos conceitos básicos antes de avançar.
  • Faça resumos e fichas: Escreva fórmulas e exemplos para revisão rápida.
  • Use técnicas de repetição espaçada: Revise conteúdos em intervalos programados para fixação a longo prazo.
Estabeleça metas pequenas e específicas para cada sessão de estudo. Por exemplo, "Hoje vou dominar fatoração e resolver 10 exercícios sobre o tema".
Evite estudar apenas na véspera da prova. O aprendizado acumulado é sempre mais eficiente.
