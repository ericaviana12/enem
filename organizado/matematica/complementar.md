1. Conjuntos Numéricos

O que são?
São grupos de números que compartilham características em comum.

Conjuntos principais:

| Conjunto        | Exemplo                | Características                     |
| --------------- | ---------------------- | ----------------------------------- |
| Naturais (N)    | 0, 1, 2, 3...          | Números usados para contar          |
| Inteiros (Z)    | -3, -2, -1, 0, 1, 2... | Inclui negativos e zero             |
| Racionais (Q)   | 1/2, 0,75, -3          | Podem ser escritos como fração      |
| Irracionais (I) | π, √2, e               | Decimais infinitos e não periódicos |
| Reais (R)       | Todos acima            | Abrange todos os anteriores         |

2. Porcentagem e Regra de Três

Porcentagem:
Indica "quantas partes de 100".

Exemplo de cálculo:
30% de 200 → (30/100) × 200 = 60

Regra de Três Simples (proporção direta ou inversa):
Proporção direta: Quando uma aumenta, a outra também.
Proporção inversa: Quando uma aumenta, a outra diminui.

Exemplo típico de ENEM:
Se 4 máquinas produzem 800 peças em 2 horas, quantas peças 6 máquinas produzem no mesmo tempo?

3. Funções

Função do 1º grau (Linear):
Forma: f(x) = ax + b
Gráfico: uma reta.

Função do 2º grau (Quadrática):
Forma: f(x) = ax² + bx + c
Gráfico: uma parábola (U ou ∩)

Vértice → ponto máximo ou mínimo.
Raízes → onde a parábola corta o eixo x.

Função Exponencial:
Cresce ou decresce de forma acelerada. Exemplo: f(x) = 2^x

Função Logarítmica:
Inversa da exponencial. Exemplo: f(x) = log2(x)

4. PA (Progressão Aritmética) e PG (Progressão Geométrica)

PA (Soma de termos em sequência com diferença fixa):
Exemplo: 2, 5, 8, 11... (razão 3)

Fórmulas:
Termo geral: an = a1 + (n – 1)r
Soma: Sn = (a1 + an) × n / 2

PG (Sequência com multiplicação fixa):
Exemplo: 2, 4, 8, 16... (razão 2)

Fórmulas:
Termo geral: an = a1 × r^(n-1)
Soma: Sn = a1 × (r^n – 1) / (r – 1)

5. Análise Combinatória

Fatorial (!):
Exemplo: 4! = 4×3×2×1 = 24

Permutação:
Ordem importa e usa todos os elementos.
Exemplo: Quantas maneiras de ordenar 4 pessoas? → 4! = 24

Arranjo:
Ordem importa, mas só usa parte dos elementos.
Exemplo: Formar senhas com 3 dígitos diferentes escolhidos de 5 números.

Combinação:
Ordem não importa.
Exemplo: Escolher 3 alunos entre 5 para formar um grupo.

6. Probabilidade

Conceito básico:
Probabilidade = casos favoráveis / casos possíveis

Exemplo:
Lançar um dado → Chance de sair 2: 1/6.

Eventos Independentes:
Dois eventos não interferem um no outro.
Exemplo: Jogar dois dados.

Probabilidade Condicional:
Probabilidade de um evento acontecer, dado que outro já aconteceu.

7. Geometria

Áreas:
Fórmulas básicas para cálculo de superfícies planas.

| Figura    | Fórmula da Área         |
| --------- | ----------------------- |
| Quadrado  | A = lado²               |
| Retângulo | A = base × altura       |
| Triângulo | A = (base × altura) / 2 |
| Círculo   | A = π × r²              |

Perímetro:
Soma de todos os lados.

Volume:
Sólido	Fórmula do Volume
Cubo	V = lado³
Paralelepípedo	V = base × altura × profundidade
Cilindro	V = π × r² × altura

Teorema de Pitágoras:
Em triângulos retângulos:
a² = b² + c²

9. Estatística

Média:

11. Matemática Financeira

Juros Simples:
Fórmula:
J = C × i × t

Exemplo:
R$ 1.000 a 2% ao mês por 3 meses → J = 1.000×0,02×3 = R$ 60

Juros Compostos:
Fórmula:
M = C × (1 + i)^t

Exemplo:
R$ 1.000 a 2% ao mês por 3 meses → M = 1.000 × (1,02)^3 ≈ R$ 1.061,21

12. Equações e Inequações

Equação do 1º Grau:
Exemplo:
2x + 4 = 10 → x = 3

Equação do 2º Grau:
Exemplo:
x² – 5x + 6 = 0 → x = 2 ou x = 3

Usa a fórmula de Bhaskara.

Inequações:
Resolvemos como uma equação, mas com atenção ao sinal:
x – 3 > 2 → x > 5

13. Matrizes e Determinantes

Matrizes:

Determinante da matriz 2×2:
(1×4) – (2×3) = 4 – 6 = -2

14. Geometria Analítica

Ponto:
Coordenadas (x, y). Exemplo: (3, 2)

Equação da Reta:
y = mx + n → m é a inclinação, n é o ponto de interseção com eixo y.

Distância entre dois pontos:
d = √((x2 – x1)² + (y2 – y1)²)

Circunferência:
Fórmula: (x – x0)² + (y – y0)² = r²
