1. Números e Operações

1.1 Conjuntos Numéricos
Naturais (ℕ): {0, 1, 2, 3, ...}
Inteiros (ℤ): {..., -2, -1, 0, 1, 2, ...}
Racionais (ℚ): Números que podem ser escritos como fração: p/q (q ≠ 0).
Irracionais: Decimais infinitos e não periódicos (ex: π, √2).
Reais (ℝ): União dos racionais e irracionais.

1.2 Operações Básicas
Potenciação:
Exemplo:
2³ = 2×2×2 = 8

Radiciação:
Exemplo:
√9 = 3

2. Álgebra

2.1 Expressões Algébricas
Uso de letras (variáveis) para representar números.

Exemplo de fatoração:
x² - 9 = (x - 3)(x + 3)

2.2 Equações e Inequações
Equação do 1º grau:
ax + b = 0

Exemplo:
2x + 3 = 7
2x = 4 ⇒ x = 2

Equação do 2º grau:
ax² + bx + c = 0

Fórmula de Bhaskara:
Δ = b² - 4ac
x = (-b ± √Δ) / 2a

Inequações:
Exemplo:
x + 2 > 5 ⇒ x > 3

3. Funções

3.1 Definição
Relação entre dois conjuntos: cada x tem um único y.
Notação: f(x)

3.2 Tipos Comuns
Função Linear:
f(x) = ax + b

Função Quadrática:
f(x) = ax² + bx + c

Exponencial:
f(x) = aˣ

Logarítmica:
Inversa da exponencial.

Exemplo:
f(x) = 2x + 1
Para x = 3 → f(3) = 7

4. Geometria

4.1 Geometria Plana
Área do Triângulo:
A = (base × altura) / 2

Área do Círculo:
A = πr²

Circunferência:
C = 2πr

Pitágoras:
a² = b² + c²

4.2 Geometria Espacial

| Sólido             | Volume        | Área Total                       |
| ------------------ | ------------- | -------------------------------- |
| **Cubo**           | V = a³        | A = 6a²                          |
| **Paralelepípedo** | V = a×b×c     | A = 2(ab + bc + ac)              |
| **Cilindro**       | V = πr²h      | A = 2πr(r + h)                   |
| **Esfera**         | V = (4/3)πr³  | A = 4πr²                         |
| **Cone**           | V = (1/3)πr²h | A = πr(r + g), onde g = geratriz |

5. Trigonometria

Seno: sen(θ) = cateto oposto / hipotenusa
Cosseno: cos(θ) = cateto adjacente / hipotenusa
Tangente: tg(θ) = cateto oposto / cateto adjacente

Relação fundamental:
sen²θ + cos²θ = 1

6. Estatística e Probabilidade

6.1 Estatística
Média: Soma dos valores / número de valores
Mediana: Valor central da sequência ordenada
Moda: Valor que mais aparece

6.2 Probabilidade
Fórmula:
P = casos favoráveis / casos possíveis

Exemplo:
5 bolas vermelhas e 3 azuis:
P(vermelha) = 5/8 = 0,625 = 62,5%

7. Matemática Financeira

Juros Simples:
J = P × i × t

Montante (Juros simples):
M = P + J

Juros Compostos:
M = P × (1 + i)ᵗ

Onde:
P = capital inicial
i = taxa
t = tempo

Exemplos Práticos
Exemplo 1 – Equação do 2º Grau:
x² - 5x + 6 = 0
Δ = (-5)² - 4×1×6 = 1
x = (5 ± 1) / 2 → x = 3 ou x = 2

Exemplo 2 – Probabilidade:
Urna com 5 vermelhas e 3 azuis:
P(vermelha) = 5/8 = 62,5%
