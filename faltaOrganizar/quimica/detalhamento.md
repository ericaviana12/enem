📚 CAPÍTULO 5 – QUÍMICA (CIÊNCIAS DA NATUREZA)

🎯 OBJETIVO DO CAPÍTULO:
Te dar uma visão completa e aprofundada dos principais tópicos de Química, com teoria detalhada, exemplos de situações do dia a dia, cálculos e contextualização para vestibulares.

⚗️ 1. Estrutura Atômica

➡️ Modelos atômicos históricos:

| Modelo     | Característica Principal                                          |
| ---------- | ----------------------------------------------------------------- |
| Dalton     | Átomo como esfera maciça (bola de bilhar)                         |
| Thomson    | Átomo com elétrons dentro de uma massa positiva (pudim de passas) |
| Rutherford | Átomo com núcleo positivo e elétrons ao redor (modelo nuclear)    |
| Bohr       | Elétrons em camadas definidas, com níveis de energia              |

➡️ Estrutura atual:
Núcleo: Prótons (+) e nêutrons (neutros)
Eletrosfera: Elétrons (-)

✅ Exemplo de questão:
Quantos prótons, nêutrons e elétrons tem o átomo de sódio (Na) de número atômico 11 e massa 23?
Resposta:
Prótons: 11
Elétrons: 11
Nêutrons: 12

🧪 2. Tabela Periódica

➡️ Organização:
Grupos: colunas (famílias químicas)
Períodos: linhas horizontais (níveis de energia)

➡️ Propriedades periódicas importantes:

| Propriedade          | Tendência                            |
| -------------------- | ------------------------------------ |
| Raio atômico         | Aumenta para baixo e para a esquerda |
| Energia de ionização | Aumenta para cima e para a direita   |
| Eletronegatividade   | Aumenta para cima e para a direita   |
| Afinidade eletrônica | Aumenta para cima e para a direita   |

✅ Exemplo prático:
Por que o Flúor (F) é mais eletronegativo que o Oxigênio (O)?
Resposta: Porque está mais à direita e acima na tabela.

🧬 3. Ligações Químicas

➡️ Tipos principais:
Iônica: Transferência de elétrons (Ex: NaCl)
Covalente: Compartilhamento de elétrons (Ex: H₂O)
Metálica: Nuvem de elétrons livres (Ex: Fe, Al)

✅ Exemplo:
Por que o sal de cozinha conduz eletricidade dissolvido em água, mas não em estado sólido?
Resposta: Porque na solução aquosa, os íons ficam livres para se mover.

🌡️ 4. Reações Químicas

➡️ Tipos principais:

| Tipo          | Exemplo                        |
| ------------- | ------------------------------ |
| Síntese       | 2H₂ + O₂ → 2H₂O                |
| Decomposição  | 2H₂O → 2H₂ + O₂                |
| Simples troca | Zn + 2HCl → ZnCl₂ + H₂         |
| Dupla troca   | Na₂SO₄ + BaCl₂ → BaSO₄ + 2NaCl |
| Combustão     | CH₄ + 2O₂ → CO₂ + 2H₂O         |

➡️ Balanceamento de equações:
Lei da conservação da massa (Lavoisier):
Massa dos reagentes = Massa dos produtos.

✅ Exemplo de balanceamento:
C₃H₈ + O₂ → CO₂ + H₂O
Balanceado: C₃H₈ + 5O₂ → 3CO₂ + 4H₂O

🧮 5. Cálculos Estequiométricos

➡️ Passos para resolver:
Balancear a equação.
Relacionar as quantidades em mols.
Fazer regra de três com a massa/mol/volume.

✅ Exemplo:
Quantos gramas de CO₂ são produzidos na combustão completa de 44 g de CH₄?
Resposta: 44 g de CH₄ = 2 mols → produz 2×44 = 88 g de CO₂.

🧂 6. Soluções

➡️ Conceitos:
Soluto: O que é dissolvido.
Solvente: O que dissolve.
Concentração comum: C = m/V
Mol/L: Molaridade (M)

✅ Exemplo:
Quantos gramas de NaCl há em 500 mL de uma solução 2 mol/L?
Resposta:
M = n/V → n = M×V = 2×0,5 = 1 mol → 1×58,5g = 58,5g.

🌡️ 7. Termoquímica

➡️ Conceitos principais:
Reações exotérmicas: Liberam calor (ΔH < 0)
Reações endotérmicas: Absorvem calor (ΔH > 0)

➡️ Lei de Hess:
Soma algébrica das entalpias das reações.

✅ Exemplo:
Por que a combustão do etanol é exotérmica?
Resposta: Porque libera energia na forma de calor.

⚖️ 8. Equilíbrio Químico

➡️ Características:
Sistema fechado
As velocidades das reações direta e inversa se igualam

➡️ Princípio de Le Chatelier:
O sistema reage a uma perturbação para minimizar o efeito dela.

✅ Exemplo:
O que acontece se aumentar a temperatura de uma reação endotérmica?
Resposta: O equilíbrio desloca para o sentido dos produtos.

🧪 9. Ácidos e Bases (Teorias de Arrhenius, Brönsted-Lowry e Lewis)

➡️ Definições:

| Teoria         | Ácido               | Base               |
| -------------- | ------------------- | ------------------ |
| Arrhenius      | Libera H⁺           | Libera OH⁻         |
| Brönsted-Lowry | Doador de prótons   | Aceptor de prótons |
| Lewis          | Aceptor de elétrons | Doador de elétrons |

➡️ Exemplo:
HCl + H₂O → H₃O⁺ + Cl⁻ (Ácido segundo Brönsted)

💧 10. pH e pOH
➡️ Fórmulas:
pH = -log[H⁺]
pOH = -log[OH⁻]
pH + pOH = 14 (a 25°C)

✅ Exemplo:
Qual o pH de uma solução com [H⁺] = 1×10⁻³ mol/L?
Resposta: pH = 3 (solução ácida)

| Função            | Exemplo                         |

Qual a diferença entre etanol e metanol?

📝 13. Exercícios de Fixação

1) Diferencie ligação iônica e covalente com exemplos:
Ligação iônica: Ocorre entre metais e ametais, com transferência de elétrons. Exemplo: NaCl (sal de cozinha).
Ligação covalente: Ocorre entre ametais, com compartilhamento de elétrons. Exemplo: H₂O (água).

2) Resolva o balanceamento: C₂H₆ + O₂ → CO₂ + H₂O

Passo a passo:

Primeiro, balanceie o carbono (C):
C₂H₆ → 2 CO₂

Depois o hidrogênio (H):
C₂H₆ → 2 CO₂ + 3 H₂O

Agora, balanceie o oxigênio (O):
O lado direito tem:
(2×2) + (3×1) = 7 oxigênios

Então, fica:
C₂H₆ + (7/2) O₂ → 2 CO₂ + 3 H₂O

Para eliminar o denominador, multiplique tudo por 2:
2 C₂H₆ + 7 O₂ → 4 CO₂ + 6 H₂O

✅ Resposta balanceada: 2 C₂H₆ + 7 O₂ → 4 CO₂ + 6 H₂O

3) Calcule a massa de água formada na reação de 8g de H₂ com O₂:

Reação:
2 H₂ + O₂ → 2 H₂O

Massa molar do H₂ = 2 g/mol
8g de H₂ → 4 mols de H₂

Pela proporção da reação:
2 mols de H₂ → 2 mols de H₂O
4 mols de H₂ → 4 mols de H₂O

Massa molar da água = 18 g/mol
Massa de água formada = 4 mols × 18 g/mol = 72g de H₂O

✅ Resposta: 72g de água

4) Explique o Princípio de Le Chatelier com outro exemplo:
Se aumentarmos a pressão em uma reação gasosa com maior número de mols de gás nos reagentes, o equilíbrio se desloca para o lado com menos mols de gás.
Exemplo:
N₂ + 3 H₂ ⇌ 2 NH₃
Se aumentarmos a pressão, o equilíbrio favorece a formação de NH₃ (lado com menos mols gasosos).

5) Qual a função orgânica do etanoato de metila?
É um éster, derivado da reação entre ácido acético (ácido etanoico) e metanol.

✅ Resposta: Éster
